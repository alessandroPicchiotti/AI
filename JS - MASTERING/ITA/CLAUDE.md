## Contesto di Sviluppo dell'Applicazione

Leggere i seguenti file in ordine prima di implementare o prendere qualsiasi decisione architettonica:

1. `context/project-overview.md` — definizione del prodotto, obiettivi, funzionalità e ambito (.NET 8, SQL Server, Duende IdentityServer)
2. `context/architecture.md` — struttura del sistema, confini, modello di storage e invarianti
3. `context/ui-context.md` — tema, colori, tipografia e convenzioni dei componenti (MudBlazor / Bootstrap)
4. `context/code-standards.md` — regole e convenzioni di implementazione (C#, .NET 8, T-SQL)
5. `context/ai-workflow-rules.md` — flusso di lavoro di sviluppo, regole di scoping e approccio di rilascio
6. `context/progress-tracker.md` — fase corrente, lavoro completato, domande aperte e prossimi passi

Aggiornare `context/progress-tracker.md` dopo ogni modifica significativa all'implementazione.

Se l'implementazione modifica l'architettura, l'ambito o gli standard documentati nei file di contesto, aggiornare il file pertinente prima di continuare.
